# Charity Table Advertising App (Cactus)

A phone-first web app for charity poker nights: charities sell sponsor spaces on custom poker tables, collect artwork, approve proofs and send tables to production.

Read `AGENTS.md` first, then `docs/UPDATES.md`.

- Run: `npm install && npm start` (Node 20+, PostgreSQL via `DATABASE_URL`).
- Health check: `GET /health` returns `ok`.
- Demo charity: `/c/demo` (logins listed on `/admin` for the Cactus admin).
